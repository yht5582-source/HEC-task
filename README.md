# 衛教室戰情室

門診衛教室的任務管理與業務量統計系統。網頁放在 GitHub Pages，資料存在 Firebase，成員用院內信箱收登入連結即可使用，不需要密碼。

網址：https://yht5582-source.github.io/HEC-task/

與營養科戰情室（CND-task）共用同一個 Firebase 專案 `cnd-task`，但所有資料都存在 `hec_` 開頭的資料表，兩邊互不相通。

## 功能
- **戰情室**：當日業務量填報情況、未完成與逾期任務、本週業務量、需要注意的任務
- **任務**：負責人指派、成員自選（認領或自行提出）、完成進度、成果說明
- **業務量**：每人每日登錄各項目人次（項目可在設定中增減）
- **統計報表**：任意期間的成員統計、各項目合計、每日／每月趨勢，可匯出 CSV
- **任務分析**：依任務項目／成員／期間看執行次數、完成率、準時率
- **工作成就**：主動承接（自提、認領）與指派完成的任務
- **人員與設定**：成員名單、職稱、權限、業務量項目

## 身分與權限

| 身分 | 設定方式 | 可以做的事 |
|---|---|---|
| 主任 | 安全規則中的 `DIRECTOR_EMAIL` | 全部功能 |
| 負責人 | 人員名單權限「負責人」 | 指派／刪除任務、管理成員名單與業務量項目、登錄所有人的業務量 |
| 成員 | 人員名單權限「成員」 | 提出／認領任務、更新自己任務進度與成果、登錄自己的業務量 |

## 首次設定
1. Firebase 規則：把 `firestore.rules`（含營養科與衛教室兩部分的完整版）貼到 Firebase 主控台 → Firestore Database → 規則，`DIRECTOR_EMAIL` 換成主任信箱後發布。
2. 主任開啟網址登入，按「我是主任，進行首次設定」。
3. 貼上成員名單（每行：`姓名 <email>`），選擇負責人與其職稱，按「建立初始資料」。

本儲存庫為公開，程式碼內不含任何人員姓名或信箱；所有資料只存在 Firebase。
